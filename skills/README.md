# UniFlight Framework Agent Skill

A detailed agent skill for UniFlight 1.0.2.

## Contents
- `SKILL.md` — primary routing, operating procedure, safety/scientific boundaries, and core usage.
- `references/` — deep guides covering architecture, Python API, physics, GNC, MDL, hybrid/multi-vehicle, optimization, data, EDL, plugins, HPC, verification, benchmarking, debugging, recipes, API index, and limitations.
- Live examples, missions, and docs live in the repository root (`examples/`, `missions/`, and the project Markdown files). Do not keep copies here.
- `agents/openai.yaml` — agent metadata.

## Use
Install/extract the skill in the agent platform's skill directory, or provide the folder to an agent and instruct it to read `SKILL.md`.

The live UniFlight checkout always overrides this bundled 1.0.2 reference if versions differ.
